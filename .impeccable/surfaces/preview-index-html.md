# Surface brief: 학생 학습 화면(수학 index.html, 국어·영어 같은 틀)

Mode: Operate. 학생이 기출을 고르고 풀고, 틀린 문제를 연습으로 잇는다.

## Direction contract

FORM: 교실 칠판. seed:aabb5afd791566ce (degraded roll, no challengers)
THESIS: 이 화면은 선생님 판서처럼 "틀린 문제 → 다음 연습"을 선으로 잇는다. 같은 카드 격자를 늘어놓는 학습 사이트 기본형을 거부한다.
OWN-WORLD: 짙은 칠판 녹색 셸(윗줄·옆 레일), 분필 흰 글자, 강조는 노란 분필색 하나, 상태색(맞음 연두·틀림 분홍빛 빨강)만 의미 있을 때. 작업 영역은 밝은 종이색 판 위에 흰 문항 그림. 분필 질감·손글씨 글꼴 금지(유치함 금지).
STORY: 들어오면 내 단원 지도(정답률 색)와 다음에 풀 것(틀린 문제에서 이어진 길)을 먼저 본다. 모의고사는 연도×월 시간표 표에서 고른다.
FIRST VIEWPORT: 왼쪽 칠판 레일 내비게이션, 본문은 "다음에 풀 것" 판서 줄 + 단원 지도.
SIGNATURE: 틀린 문제와 그 변형·비슷한 기출을 잇는 노란 분필 연결선(판서 화살표).
RISK: 녹색 셸이 무겁거나 학교 게시판처럼 보일 수 있음 → 셸은 좁게, 작업 영역은 밝게.
