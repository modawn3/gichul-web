수능 기출 학습선생님용 사용 설명서

선생님 화면으로

선생님 화면에서는 학생 계정을 만들고, 반 학생들의 풀이 기록을 단원·개념·문항별로 볼 수 있습니다. 학생 화면 사용법은 학생용 사용 설명서를 보세요.

들어가기선생님과 관리자학생 계정 만들기비밀번호 초기화반 현황오답 보강 노트관리자 기능자주 묻는 질문

1들어가기

  1. 학생 사이트(이 주소)에서 받은 선생님 아이디로 로그인합니다.
  2. 왼쪽 메뉴 맨 아래(휴대폰은 오른쪽 위 동그라미)의 선생님 화면을 누르면 선생님 화면이 열립니다. 주소 뒤에 teacher.html을 붙여 바로 들어와도 됩니다.
  3. 선생님 화면에서도 같은 자리의 문제 풀기를 누르면 학생 화면으로 돌아갑니다. 선생님도 학생처럼 문제를 풀어 볼 수 있습니다.

화면은 왼쪽 짙은 녹색 메뉴(휴대폰은 화면 맨 아래 메뉴)로 바꿉니다. 메뉴는 반 현황 오답 보강 노트 학생 계정 세 개이고, 관리자에게는 문항 이미지 올리기가 하나 더 보입니다(지금은 그림이 자동으로 올라가서 쓸 일이 거의 없습니다).

2선생님과 관리자

  • 선생님: 관리자가 지정한 담당 반의 학생만 보고, 담당 반 학생 계정만 만들거나 비밀번호를 초기화할 수 있습니다.
  • 관리자: 모든 반을 보고, 선생님 계정 만들기, 담당 반 지정, 계정 지우기, 문항 이미지 올리기를 할 수 있습니다.
처음 들어왔는데 "담당 반이 지정되지 않았습니다"가 보이면 관리자에게 담당 반 지정을 요청하세요.

3학생 계정 만들기 (명단으로 한꺼번에)

  1. 학생 계정 탭에서 예시 양식 내려받기로 양식을 받습니다.
  2. 엑셀에서 아이디, 이름, 학년, 반, 번호(필수)와 비밀번호(선택)를 채웁니다. 아이디는 영문 소문자와 숫자로, 학번(예: 30201)을 쓰면 편합니다.
  3. 엑셀 표를 복사해 입력 칸에 붙여 넣거나 CSV 파일을 고른 뒤 확인하기를 누릅니다.
  4. 읽은 명단이 맞으면 N명 계정 만들기를 누릅니다.
  5. 끝나면 결과 내려받기(CSV)로 아이디와 비밀번호 목록을 받아 학생들에게 나눠 줍니다.
비밀번호 칸을 비우면 6자리 숫자를 만들어 줍니다. 만들어진 비밀번호는 결과 화면에서만 보이니, 화면을 닫기 전에 꼭 결과를 내려받으세요.
학생에게는 아이디·비밀번호와 함께 학생용 사용 설명서 주소를 알려 주면 됩니다. 처음 로그인한 뒤 비밀번호를 바꾸도록 안내해 주세요.

4비밀번호 초기화

학생이 비밀번호를 잊었을 때: 학생 계정 탭의 비밀번호 초기화 칸에 학생 아이디를 넣고 새 비밀번호 만들기를 누릅니다. 바로 아래에 새 비밀번호가 나오니 학생에게 알려 주세요. 풀이 기록은 그대로 남습니다.

5반 현황 보기

위의 칸에서 과목(수학, 영어, 국어, 고2 통합사회·통합과학), 반, 기간(전체, 최근 7일, 최근 30일)을 고릅니다. 바로 아래 짙은 녹색 칠판에 반 이름과 학생 수, 최근 7일 푼 학생, 풀이 수, 반 정답률이 나옵니다. 표는 고른 과목의 기록만 셉니다. 영어는 단원 대신 유형과 소재, 국어는 영역과 문항 유형으로 나옵니다.

  • 학생별: 푼 문항 수, 정답률, 최근 7일 풀이 수, 변형 문제 풀이 수, 마지막 활동. 학생 줄을 누르면(키보드는 Tab으로 가서 Enter) 그 학생의 단원별 정답률과 지금 틀린 상태인 문항이 나옵니다.
  • 단원별 정답률, 약한 핵심 개념(정답률 낮은 순): 수업에서 다시 다룰 단원·개념을 고를 때 씁니다.
  • 많이 틀린 문항: 처음 풀 때 틀린 학생 비율이 높은 순서이고, 많이 고른 오답도 보여 줍니다. 문항을 누르면 문제 그림과 정답이 나옵니다.

표 내려받기(CSV)로 학생별 표를 엑셀로 받을 수 있고, 새 기록은 새로 고침으로 다시 불러옵니다.

정답률은 문항마다 마지막으로 푼 결과로 셉니다. 틀렸다가 다시 풀어 맞히면 맞힌 것으로 바뀝니다.

6오답 보강 노트 (모의고사 마킹 리스트로 학생별 인쇄본)

  1. 오답 보강 노트 탭에서 학교 마킹 리스트 엑셀 파일을 고릅니다. 시험마다 한 파일이고, 여러 개를 함께 넣어도 됩니다(예: 6월 모평, 9월 모평, 10월 학평). 학교에서 받은 원본 그대로 넣으면 됩니다.
  2. 파일마다 어느 시험인지 고릅니다. 파일 이름에 연도·월이 있으면 미리 골라 둡니다.
  3. 반과 과목당 문항 수(기본 10)를 정하고 학생별 보강 문항 고르기를 누릅니다.
  4. 학생 표에서 줄 끝의 인쇄 화면(한 명) 또는 반 전체 인쇄 화면을 누르고, 그림이 다 나오면 인쇄 / PDF로 저장을 누릅니다. 인쇄 창에서 대상을 "PDF로 저장"으로 바꾸면 파일로 받을 수 있습니다.
마킹 리스트는 선생님 컴퓨터의 브라우저 안에서만 읽고 서버에 올리지 않습니다. 이름 열은 읽지 않아 화면과 인쇄본에는 반·번호만 나옵니다. 창을 닫거나 새로 고치면 넣은 파일은 사라집니다.
  • 국어·영어·수학만 봅니다. 넣은 시험들의 오답을 모두 모아 쉬운 문항(난이도 하→중→상) 먼저, 같은 난이도면 두 번 이상 시험에서 틀린 영역 먼저 고르고, 한 영역에서는 3문항까지만 고릅니다.
  • 틀린 문항마다 비슷한 실제 기출을 하나씩 고릅니다(변형 문항 없음). 넣은 시험 회차는 빼고, 원래 문항보다 한 단계 넘게 어려운 문항은 고르지 않습니다.
  • 미적분·기하 선택자는 공통(1~22번)만, 영어는 읽기(18~45번)만 채점합니다. 한 시험에 답이 비어 있으면(결시) 나머지 시험 기록으로 만듭니다.
  • 인쇄본: 한눈에 보기 표와 과목별 목록 → 2단 문항(국어는 지문 포함, 긴 지문은 글줄 사이 빈 곳에서 나눠 다음 단으로) → 정답표와 해설.
반 전체는 그림이 많아 처음에 1~2분 걸릴 수 있습니다. "확인할 점" 칸에 답이 비었거나 같은 번호를 몰아 찍은 것으로 보이는 시험이 나오니, 그 학생의 자료는 한 번 더 살펴 주세요.

7관리자 기능

  • 선생님 계정 만들기: 명단에 역할 열을 "선생님"으로, 담당반 열에 3-1;3-2처럼 적어 학생과 같은 방법으로 만듭니다.
  • 담당 반 지정: 선생님 아이디와 반(예: 3-1;3-2)을 넣고 지정.
  • 계정 지우기: 아이디(여러 개는 쉼표)를 넣고 지우기. 풀이 기록도 함께 지워지고 되돌릴 수 없습니다.
  • 문항 이미지 올리기: 이제 쓰지 않아도 됩니다. 새 회차·새 과목의 문항·해설 그림은 사이트를 고칠 때 자동으로 저장소에 올라갑니다. 예전 방식(기출학습 폴더의 img_q.js, img_s_연도.js 파일을 골라 올리기)이 필요할 때를 위해 탭은 남겨 두었습니다.

?자주 묻는 질문

학생이 로그인이 안 된다고 해요.

학생 계정의 등록된 계정 목록에서 아이디가 맞는지 확인하고, 맞으면 비밀번호를 초기화해 주세요.

계정을 만들 때 "담당 반 학생만 만들 수 있습니다"가 나와요.

명단의 학년·반이 내 담당 반이 아닌 경우입니다. 학년·반을 확인하거나 관리자에게 담당 반 추가를 요청하세요.

학생 기록이 안 보여요.

기간이 "최근 7일"로 되어 있지 않은지 확인하고 새로 고침을 눌러 보세요. 학생이 인터넷이 끊긴 채 풀었다면 다시 연결될 때 올라옵니다.
